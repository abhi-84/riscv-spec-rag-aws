RAG based chatbot for to answer RISCV related queries based on on 6 RISC-V specification PDFs. 
This project started from the LLM Engineering course POC (Ed Donner) and this repo upgrades it to production on AWS. 
Spec PDFs are not included; sources are listed below.

https://github.com/riscv-non-isa/riscv-brs/releases/download/v0.9/riscv-brs-spec.pdf
https://docs.riscv.org/reference/rva20-rvi20-rva22/v1.0/_attachments/RISC-V_Profiles.pdf
https://docs.riscv.org/reference/rva23/_attachments/rva23-profile.pdf
https://docs.riscv.org/reference/rvb23/_attachments/rvb23-profile.pdf
https://github.com/riscv-non-isa/riscv-sbi-doc/releases/download/v2.0/riscv-sbi.pdf
https://docs.riscv.org/reference/isa/extensions/vector/_attachments/riscv-v-spec.pdf
